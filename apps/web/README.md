# ApexGraphSwarm workbench

See the [project README](../../README.md). Run `npm run dev` from this directory and open http://127.0.0.1:3010. The optional integrations use server-only configuration in `.env.local`; `.env.example` documents available settings. The graph is built from this project by the standard-library Python package.

`npm test`, `npm run typecheck`, and `npm run build` verify the web application.
